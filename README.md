# 🧸 Bearly Watching 🍓

A tiny macOS app that turns your Safari YouTube session into Discord Rich Presence.

Bearly Watching detects YouTube videos playing in Safari — even when the YouTube tab is not active — and displays your current watch session on Discord.

Everything runs locally on your Mac.

## ✨ Features

- 🎬 Detect YouTube videos across Safari tabs
- 📺 Detect YouTube channel name
- ▶️ Playing detection
- 💤 Pause detection
- 🍓 Finished video detection
- 🔴 Live stream detection
- 🖼️ Dynamic YouTube thumbnails
- ⏱️ Playback progress
- 🔗 Watch Video button
- 🔌 Discord auto-reconnect
- 🛡️ Safari / Discord error handling
- 🚀 LaunchAgent background support
- 🔒 No YouTube login or server required

## 🛠️ Requirements

- macOS
- Safari
- Discord Desktop
- Python 3
- `Allow JavaScript from Apple Events` enabled in Safari
